- `mini-origin-plasticity-v5-summary.json` — aggregate results from five independent shortcut-resistant searches.
- `mini-origin-plasticity-v5-seed55.json` — strongest evolved plasticity law, controls, history, and hidden scores.
- `MINI_ORIGIN_V05_REPORT.md` — benchmark correction, mechanism interpretation, limitations, and next gate.

The v0.5 result is a replicated within-lifetime local-learning breakthrough inside Mini-ORIGIN. The candidate operator basis remains human-designed, so the result is not presented as a new universal theory of learning.
