# Mini-ORIGIN v0.89 novelty audit — 2026-08-23

## Decision

The current response-cost exact-search mechanism is **not cleared for a novelty, world-first, or breakthrough claim**. The strongest defensible interpretation is that Mini-ORIGIN has rediscovered and combined exact-search reductions that appear to sit inside established dynamic-programming / decision-tree / diagnostic-test-sequencing principles, and has shown unusually strong internal and some fresh-external computational evidence on its diagnosis-like workload.

The research direction therefore changes from "obtain another fresh dataset speedup" to "test whether a frozen, domain-independent discovery/reduction mechanism transfers mechanically across structurally different exact-search families, then seek a genuinely new reduction or theorem against contemporary baselines."

## Mechanism decomposition

### 1. Response-partition quotient

Current Mini-ORIGIN behavior:

- At a search state, group queries only when they induce the same nonempty response partition of the surviving hypotheses.
- Align the per-response immediate-cost vector on that common partition.
- Remove a query when another query in the same partition class has componentwise no-greater immediate cost and is strictly cheaper on at least one outcome.
- Equal vectors use a deterministic tie break.

Assessment:

- Correctness is a direct Bellman-style dominance consequence when continuation value is determined by the successor state and path-cost aggregation is monotone in nonnegative immediate costs.
- This is useful and exact, but the audit does not currently support presenting the underlying dominance fact itself as a new theorem.

Relevant implementation: `mini-origin/src/mini_origin/response_cost_pareto_v56.py`.

### 2. One-step full-diagnosis lower bound

Current Mini-ORIGIN behavior:

- After a candidate first query, every impure child must execute at least one remaining separating test before full diagnosis can be completed.
- The lower bound adds the cheapest possible immediate expected separating-test cost in each child and forms a compatible worst-cost lower bound.
- Once a full-diagnosis incumbent exists, candidates whose optimistic bound cannot improve the lexicographic incumbent are pruned.

Assessment:

- This is an admissible exact bound and has produced large empirical expansion reductions in the project.
- The underlying "at least one separating action remains" argument is structurally simple; no novelty claim is made without a much deeper theorem-level literature comparison.

Relevant implementation: `mini-origin/src/mini_origin/response_cost_lower_bound_v65.py`.

### 3. Response-lattice closure

Current Mini-ORIGIN behavior:

- Treat complete query-response blocks as partitions.
- Compute the common refinement generated by a set of queries.
- A query lies in the closure when the generator partition refines that query's response partition.
- v0.85 uses this only as a zero-state fallback in state selection; it is not the main solver pruning mechanism.

Assessment:

- This is naturally interpretable as functional dependency / partition refinement structure.
- It improves structural coverage but is not presently a standalone algorithmic novelty claim.

Relevant implementation: `mini-origin/src/mini_origin/response_lattice_closure_v85.py`.

## Prior-art anchors checked

This audit is intentionally conservative rather than exhaustive. At minimum, the current claim boundary must respect:

1. M. R. Garey, **Optimal Binary Identification Procedures**, SIAM Journal on Applied Mathematics 23(2), 1972, DOI: 10.1137/0123019. The paper formulates finite hypothesis identification with tests, priors and test costs and gives a dynamic-programming algorithm for optimal identification procedures.
2. L. Hyafil and R. L. Rivest, **Constructing optimal binary decision trees is NP-complete**, Information Processing Letters 5(1), 1976, DOI: 10.1016/0020-0190(76)90095-8.
3. A. Saettler, E. Laber and F. Cicalese, **Approximating decision trees with value dependent testing costs**, Information Processing Letters 115(6-8), 2015, DOI: 10.1016/j.ipl.2015.02.006. This establishes that outcome/value-dependent test costs are an existing decision-tree model rather than a new Mini-ORIGIN problem definition.
4. J. G. M. van der Linden, M. van den Bos and E. Demirović, **Search Strategies for Optimal Classification and Regression Trees**, arXiv:2607.28170, submitted 2026-07-30. This contemporary work unifies and evaluates many exact ODT search strategies and materially raises the baseline for any claim that a pruning/search strategy is new or state of the art.
5. The sequential fault-diagnosis / optimal-test-sequencing literature also formulates diagnosis as an AND/OR decision-tree search minimizing expected testing cost, including AO* and related exact/heuristic methods.

## What remains genuinely interesting

The project can still become scientifically important if it demonstrates something stronger than the individual reductions above:

1. **Frozen cross-domain transfer:** the same generated transformation, with no domain-specific dominance predicate, preserves exact optima and removes meaningful search across unrelated exact-search families.
2. **Autonomous rediscovery:** the discovery engine derives known reductions from transition/cost semantics rather than being manually given each reduction. This would be a systems result, not a new-mathematics claim.
3. **Novel reduction discovery:** after the generic mechanism is frozen, it proposes a reduction or admissible bound that survives a serious prior-art audit and beats strong contemporary exact baselines.
4. **Independent reproduction:** another implementation/team reproduces the theorem and computational effect.

## v0.89 role

v0.89 is only item (1)'s synthetic precursor. It applies one frozen Bellman action quotient to:

- adaptive diagnosis,
- weighted set cover,
- acyclic shortest path.

The pass condition requires exact raw-vs-quotient objective agreement on all preregistered instances and positive aggregate action-expansion reduction in every family.

Even a perfect v0.89 result does **not** establish external generalization, novelty, state of the art, or a breakthrough. It only demonstrates that the mechanism has been factored out of the diagnosis code as a real domain-independent exact transformation.

## Next claim gate after v0.89

If v0.89 passes, the next research version must be separately preregistered before external instance access. It should use at least two genuinely external families not used to design the v0.89 adapters, compare against strong family-native baselines, preserve all failures, and keep the novelty audit separate from performance evidence.
