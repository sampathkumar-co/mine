# Public frontier map — 2026-07-28

This file records the public baseline used to prevent novelty drift. It is a literature map, not a claim that unpublished systems do not exist.

## Systems and capabilities already demonstrated

| Work | Demonstrated capability | Why it does not yet satisfy Lexigen Language Genesis L5 |
|---|---|---|
| DreamCoder (2020) | Learns reusable symbolic abstractions and grows domain languages through wake-sleep program induction. | Operates through a supplied program-learning framework and domain setup; it does not establish autonomous diagnosis of representational insufficiency plus verifier co-evolution and cross-domain capability genesis. |
| Coconut (2024) | Performs reasoning in continuous latent states rather than decoding every intermediate step into language. | Changes the reasoning channel, but does not emit persistent, explicit, independently executable semantics for invented primitives. |
| Compressed Chain of Thought (2024) | Uses dense continuous contemplation tokens to compress reasoning. | Compression is not autonomous executable vocabulary invention. |
| TheoryCoder-2 (2026) | Learns reusable abstractions for hierarchical planning from experience. | Abstractions are synthesized inside a supplied planning/program-synthesis architecture and task ontology. |
| ADVENT (2026) | Invents Prolog predicates with execution-guided refinement and cross-task reuse. | New predicates live inside fixed Prolog semantics; the system does not invent the interpreter-level operations or verifier needed for a genuinely new capability class. |
| UniPred (2025) | Learns symbolic predicates for robot planning using foundation-model proposals and grounded feedback. | Predicate learning remains inside a predefined symbolic world-model framework. |
| CLSR / Language Symbolism Frameworks (2026) | LLM agents invent and evolve compact symbolic communication protocols, reducing generated-token cost. | The objective is communication efficiency and reasoning accuracy; it does not prove that invented semantics unlock a capability unavailable to equal-budget fixed-language systems. |
| Latent Thought Flow (2026) | Learns variable-length stochastic latent reasoning trajectories. | Improves latent reasoning allocation, but does not yield a persistent executable language with independently testable operators. |
| Emergent Communication for Rules Reasoning (2023) | Produces stable compositional communication that transfers rules across attributes and tasks. | Emergent messages are communication protocols in a fixed game, not autonomous interpreter-extending cognitive primitives. |
| Vocabulary and Verifier Gaps (2026) | Formalizes the missing vocabulary and verifier problems for open-ended AI. | This is a frontier analysis and agenda, not an end-to-end demonstrated solution. |

## Frozen novelty boundary

The following are **not sufficient** for a Language Genesis claim:

1. shorter prompts or chains of thought;
2. latent vectors without explicit executable semantics;
3. renamed known operations;
4. task-specific macros;
5. predicates inside an unchanged host logic;
6. a human-authored DSL;
7. improved search with more inference, agents, samples, or compute;
8. gains on one benchmark family without transfer;
9. a language whose utility disappears when the benchmark generator changes surface encoding;
10. self-evaluation without a separately implemented verifier.

## Current public frontier estimate

The public literature convincingly reaches L2 and L3. Some systems show pieces of L4: persistent abstraction libraries, compact evolving protocols, and cross-task predicate reuse. No cited system demonstrates the complete L5 loop under a frozen, blind, equal-resource protocol:

> detect representational inadequacy → invent new executable semantics → safely integrate them → extend trustworthy evaluation → unlock a hidden transferable capability → reproduce independently.

That complete loop is the research target. This assessment must be re-audited before any external novelty claim.
