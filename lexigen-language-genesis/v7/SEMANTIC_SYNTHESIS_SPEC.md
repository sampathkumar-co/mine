# Lexigen v7 — Typed Semantic Synthesis

Status: research milestone; no breakthrough claim.

## Objective

Replace post-failure hand-written ARC operators with synthesized executable semantic programs built from lower-level relational primitives.

The v7 target is the previously diagnosed frame-and-hole transplantation behaviour. The complete operation must not appear as a Python primitive in the v7 language. Instead, v7 must compose:

1. connected-region extraction;
2. border and boundary relations;
3. uniform-frame predicates;
4. normalized-shape predicates;
5. deterministic one-to-one matching;
6. source erasure and destination painting.

## Required evidence

- serialized typed semantic AST;
- exact reconstruction of all published gate-4 demonstrations;
- deterministic synthesis from demonstrations;
- independent portable runtime agreement;
- AST-bound verifier certificate;
- negative controls rejecting area-only and bounding-box-only matches;
- no access to sealed gate-4 outputs;
- no claim that the human-supplied meta-grammar is itself novel.

## Claim boundary

Passing v7 means Lexigen can construct one previously manual operator from reusable relational semantics. It does not yet mean autonomous open-ended language invention because the typed semantic grammar is human supplied. That stronger gate begins at v8.
