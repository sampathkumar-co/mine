# Lexigen Language Genesis v19 - quantified production invention

v18 demonstrated that the fixed v17 constructive language produced no program on ten untouched sealed gates. v19 therefore changes the architecture rather than expanding another task-family template.

The v19 inventor composes a serialized executable production from a smaller typed substrate:

- 4-neighbour graph components;
- generic component measurements;
- comparisons;
- higher-order filtering;
- set union;
- generic painting.

The development target is v18 gate 11, which is permanently unscored. Only its visible demonstrations are used for invention. The original sealed outputs remain unopened and are never counted as v19 evidence.

The inventor must discover a production absent from the v17 grammar, reproduce it in an independently implemented runtime, beat the frozen v17 baseline on the visible demonstrations, and fail when the decisive primitive is ablated.

Even a full pass is mechanism evidence, not a world-level breakthrough. The typed substrate and feature catalog remain human supplied.

## Integrity audit

The initial v19 working directory contained two incompatible outcomes. The preregistered gate-9 axis-production smoke fit six demonstrations but had no fresh accepted cases, and a later gate-11 component-hole report was generated outside that precommit. A 10,000-case rerun of the preserved gate-9 implementation failed immediately because its unique-axis reduction found no candidate on a fresh case.

Both outcomes are preserved. The gate-11 report is classified as unpreregistered and currently unreproducible; the gate-9 result is classified as a demonstration-only negative transfer result. Neither is valid frozen v19 evidence, neither supports transfer, and neither supports autonomous semantic-substrate invention.
