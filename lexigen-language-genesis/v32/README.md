# Lexigen v32 full-grammar transfer

v32 tests the complete 23,916-program source-induced v30 grammar on 64 identities never used by v21-v31.

Every task receives six deterministic demonstrations. The exact memoized evaluator preserves the frozen candidate order and records all exact candidates. The minimum exact candidate under that order is selected automatically.

Any selected candidate immediately receives 100 fixed fresh cases. The frozen AST runtime and an independent implementation of all source-grammar operators must both match every target. No task, case or post-result replacement is allowed.

A fresh pass would be another public fresh-validated identity solved by the source-induced grammar architecture. It would not establish outside-human reproduction or a world-level breakthrough.
