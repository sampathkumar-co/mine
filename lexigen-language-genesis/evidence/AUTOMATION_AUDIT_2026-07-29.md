## Frontier re-audit

The current work remains below an external Language Genesis breakthrough because nearby public systems already establish important parts of the path:

- DreamCoder grows reusable symbolic abstractions inside a supplied program-learning framework: https://arxiv.org/abs/2006.08381
- Stitch learns compressive library abstractions from program corpora and substantially improves library-learning efficiency: https://arxiv.org/abs/2211.16605
- Leroy extends library learning to imperative-language ASTs: https://arxiv.org/abs/2410.06438
- ARC-GEN provides reproducible procedural external ARC task generation and now covers ARC-AGI task families: https://github.com/google/ARC-GEN

These strengthen, rather than weaken, the claim boundary. Compression, macros, predicate induction, and supplied-grammar synthesis are not sufficient. A credible external result must show a capability unavailable to an equal-budget fixed-language baseline and must depend on a serialized invented executable semantic extension.

## Frozen next gate: v7

The next scientifically valid step is typed semantic synthesis of the frame-and-hole transplantation behavior from lower-level relational primitives. The complete transplant operation must not appear as a host-language primitive.

Required evidence before any new hidden task:

1. deterministic synthesis of a serialized typed semantic AST from published training examples only;
2. exact reconstruction of all six published gate-4 training pairs;
3. an independently implemented portable interpreter agreeing on every example and negative control;
4. an AST-bound verifier certificate;
5. equal-budget comparison against the frozen v5/v6 fixed-language synthesizers and a no-library baseline;
6. negative controls rejecting area-only, bounding-box-only, color-only, and ordering-only shortcuts;
7. a frozen commit and evidence hashes before selecting any new ARC-GEN task;
8. one-shot hidden-task execution with candidate predictions committed before scoring.

Passing v7 would demonstrate synthesis of one previously manual operator from reusable relational semantics. It would still not establish open-ended language invention because the typed grammar is human supplied. A stronger v8 gate must permit the vocabulary and verifier grammar themselves to co-evolve under externally frozen tasks.
