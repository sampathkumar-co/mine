# Lexigen v30: Source-Induced Motif Grammar

v30 replaces v29's single rigid skeleton with a bounded typed grammar induced only from the three frozen v28 exact programs.

The grammar may recombine observed productions, but cannot add unseen operators or task-specific rules. Twenty fresh identities are fixed before implementation. Validation generators remain unopened until the grammar enumerator, candidate order, tests, and workflow are committed.

Any exact six-example candidate is frozen by the preregistered minimum order before 1,000 fresh cases, independent runtime agreement, and verifier co-synthesis. No world-level claim is permitted before all those gates pass.
